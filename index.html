管理员登录

本页不保存任何数据：登录后浏览器直接用你的 GitHub 令牌读私有数据仓 ，在本机统计。 没有该仓库权限的人打开这个地址什么也看不到。

建议用 Fine-grained token：Repository access 只选 pa-stats，Permissions → Contents 选 Read-only（要管理权限再加 Administration: Read and write）。 令牌只存在这台电脑的浏览器里（localStorage），点「退出」即清除。
