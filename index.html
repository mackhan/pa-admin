管理员登录

本页不保存任何数据：登录后浏览器直接用你的 GitHub 令牌读私有数据仓 ，在本机统计。 没有该仓库权限的人打开这个地址什么也看不到。

令牌要求：Repository access 勾 Only select repositories → mackhan/pa-stats；Permissions → Contents: Read-only（要在「权限管理」里加人，再加 Administration: Read and write）。 令牌只存在这台电脑的浏览器里（localStorage），登录后右上角可随时复制出来另存，点「退出」即清除。
